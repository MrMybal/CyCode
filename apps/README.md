# Companion applications

- [CyCodeReader](https://github.com/MrMybal/CyCodeReader): independent native
  code/text editor, now developed and built in its own repository.

The IDE remains under `app/`. Its shared editor/file libraries are consumed from
CyCodeReader's `editor/` directory at the revision in app/editor-source.lock.json.
No Reader application source or executable target remains in this repository.
