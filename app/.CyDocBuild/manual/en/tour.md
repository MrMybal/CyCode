## Help and navigation {#help-flow}

Ctrl+F1 opens this manual; Shift+F1 opens help for the current tool. F1 also opens help in the Rider and Visual Studio profiles. The VS Code profile keeps F1 for its action palette.

The manual's header searches pages, examples and API operations. Ctrl+K opens the search dialog. Expand sidebar topics for their subpages. Language selection keeps the same page and explicit section. Reading positions are retained when browser storage is available.
