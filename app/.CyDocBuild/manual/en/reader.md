## Open the installed reader {#open}

Help > Documentation or Ctrl+F1 opens the installed `Documentation.html` in your
system browser with a local `file://` address. Keep its entire Documentation
folder together: DocData contains scripts, styles, images and module resources.
No server, CDN, Node or connection is needed to read it. External repository/licence
links still need a connection. The development toolchain is not part of the reader.

Shift+F1 and tool-window Help open the relevant page/section in the selected
application language. The illustrated tour opens its named image directly.
If the local manual is missing, restore the complete application package rather
than replacing the reader with its Markdown sources.

## Find and keep your place {#navigate}

Search in the header or press Ctrl+K. Results cover prose, code and API operations;
use content/language filters where offered. Expand the sidebar tree with keyboard
or pointer. Language selection retains the page and explicit anchor. English is
the default; the complete French edition has matching addresses.

My space contains personal bookmarks and notes. Their persistence and remembered
reading positions depend on the browser's file-origin storage policy. They are
local reader data, not workspace edits. The six reader themes are selected in
the reader; the system browser does not automatically inherit CyCode's DPI/theme.

## Images, galleries and diagrams {#media}

Enlarge an image inside the same window and use zoom/pan controls. Escape reduces
it. Minimal controls appear on hover or keyboard focus and remain visible for
touch input. Galleries mount the selected image; use their next/previous controls.
Static SVG diagrams explain workflows without a 3D or graph runtime.
The [interface map](doc:tour#interface?media=interface-image) is an illustration,
not a screenshot. No video, GIF-frame or mesh reader is required for this manual.
