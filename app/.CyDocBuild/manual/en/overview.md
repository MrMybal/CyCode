## Start here {#getting-started}

CyCode is a native IDE for code, projects and development tools. Start with the task you want to complete:

- [Open a solution or project](doc:quickstart#first-work).
- [Find your way around the interface](doc:tour#interface).
- [Edit and save a document](doc:editing#documents).
- [Find text, files or symbols](doc:search#find).
- [Work on an Unreal project](doc:unreal#engine).
- [Review and commit changes](doc:git#changes).

## Platforms and tools {#platforms}

The downloadable application package is for Windows x64. It needs the Visual C++ 2022 x64 runtime and an OpenGL 3.3 driver. Compilers, language servers, Git and debug adapters have their own installation requirements; see [language services](doc:languages#services).

Use a separate application instance for a second project. Dockable panels can become real windows and move to another monitor.
