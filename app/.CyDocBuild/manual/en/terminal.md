## Use a terminal {#terminal}

Open Terminal with Alt+F12. Choose a shell, create or select a session, type commands and use its copy/paste and scrollback controls. Interactive programs run in the selected terminal rather than in the bounded Build output view.

Project Run tasks can create a persistent terminal. Stop the running program or close its owned terminal explicitly. Restoring a workspace layout does not restart the previous shell or its processes. Terminal input is program input, not an editor transaction, and cannot be undone through document Undo.
