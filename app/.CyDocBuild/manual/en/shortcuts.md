## Common keys {#shortcuts}

| Shortcut | Action |
| --- | --- |
| Ctrl+S | Save the active text document |
| Ctrl+F | Find in the document |
| Ctrl+Shift+F | Search workspace text |
| Ctrl+Alt+F | Find a file name |
| Double Shift | Search Everywhere |
| Ctrl+F1 / Shift+F1 | Manual / contextual help |
| Alt+F12 | Terminal |

## Choose a profile {#profiles}

Options > Keyboard shortcuts selects Rider / ReSharper, Visual Studio or Visual Studio Code. Custom bindings take precedence. Chords such as Ctrl+K, Ctrl+C must complete within 1.5 seconds; Escape cancels a chord.

| Action | Rider | Visual Studio | VS Code |
| --- | --- | --- | --- |
| Rename symbol | Shift+F6 | Ctrl+R, Ctrl+R | F2 |
| Format document | Ctrl+Alt+L | Ctrl+K, Ctrl+D | Shift+Alt+F |
| Context actions | Alt+Enter | Ctrl+. | Ctrl+. |
| [Insert project snippet](doc:refactoring#snippet-catalogue) | Ctrl+J | Ctrl+K, Ctrl+X | Assign in preferences |
| [Surround with snippet](doc:refactoring#snippet-selection) | Ctrl+Alt+J | Assign in preferences | Assign in preferences |
| File structure | Ctrl+F12 | Ctrl+1, Ctrl+M | Ctrl+Shift+O |

Rider uses Ctrl+F9 for Build and Shift+F10 for Run. Ctrl+Shift+B is type definition in Rider, not another Build alias. F1 opens help except in VS Code, where it opens the action palette. These profiles use Windows/Linux-style keys; dedicated macOS schemes are not provided.
