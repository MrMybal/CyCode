Opérations publiques pour Extensions natives.

Ces contrats décrivent le service natif exposé par l’intégration SDK/MCP officielle. La disponibilité dépend du service configuré, du projet et des autorisations. Consultez le [contrat commun](doc:api-links#contract) pour les révisions, les aperçus et les tâches asynchrones.

## Opérations {#operations}

- [`plugins_list`](doc:operation-plugins-list-plugins-list) — Lister les extensions natives et leurs contributions.
- [`plugins_invoke`](doc:operation-plugins-invoke-plugins-invoke) — Invoquer une commande déclarée par une extension native.
- [`plugins_configure`](doc:operation-plugins-configure-plugins-configure) — Configurer l’activation des extensions natives.
- [`plugins_project`](doc:operation-plugins-project-plugins-project) — Lire ou modifier les préférences d’extensions du projet.
