## Ouvrir le lecteur installé {#open}

Aide > Documentation ou Ctrl+F1 ouvre le fichier installé `Documentation.html`
dans le navigateur système avec une adresse locale `file://`. Gardez tout le
dossier Documentation : DocData contient scripts, styles, images et modules.
Ni serveur, CDN, Node ni connexion n’est requis pour lire. Les liens externes vers
dépôts/licences exigent toujours une connexion. L’outillage de génération ne fait
pas partie du lecteur.

Maj+F1 et l’aide d’un panneau ouvrent sa page/section dans la langue choisie de
l’application. La visite illustrée ouvre directement son image nommée. Si le
manuel manque, restaurez le paquet complet plutôt que de remplacer le lecteur
par ses sources Markdown.

## Chercher et conserver sa position {#navigate}

Cherchez dans l’en-tête ou appuyez sur Ctrl+K. Les résultats couvrent textes,
code et opérations API ; utilisez les filtres de contenu/langage proposés.
Dépliez l’arbre latéral au clavier ou au pointeur. Changer de langue conserve
page et ancre explicite. L’anglais est la valeur par défaut ; l’édition française
complète possède les mêmes adresses.

Mon espace contient favoris et notes personnels. Leur persistance et les positions
de lecture dépendent du stockage du navigateur pour les origines fichier. Ces
données appartiennent au lecteur local, pas aux modifications du projet. Les six
thèmes se choisissent dans le lecteur ; le navigateur n’hérite pas automatiquement
du thème/DPI de CyCode.

## Images, galeries et schémas {#media}

Agrandissez une image dans la même fenêtre et utilisez zoom/déplacement. Échap
la réduit. Les contrôles minimaux apparaissent au survol ou au focus clavier et
restent visibles en tactile. Une galerie monte l’image choisie ; utilisez ses
contrôles suivant/précédent. Les SVG statiques expliquent les parcours sans moteur
3D ou graphe. Le [plan de l’interface](doc:tour#interface?media=interface-image)
est une illustration, pas une capture d’écran. Ce manuel ne requiert aucun lecteur
vidéo, de trames GIF ou de maillage.
