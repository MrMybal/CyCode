Opérations publiques pour Modèles de projets.

Ces contrats décrivent le service natif exposé par l’intégration SDK/MCP officielle. La disponibilité dépend du service configuré, du projet et des autorisations. Consultez le [contrat commun](doc:api-links#contract) pour les révisions, les aperçus et les tâches asynchrones.

## Opérations {#operations}

- [`templates_list`](doc:operation-templates-list-templates-list) — Lister les modèles de projets disponibles.
- [`templates_preview`](doc:operation-templates-preview-templates-preview) — Prévisualiser les fichiers qu’un modèle de projet créerait.
- [`templates_create`](doc:operation-templates-create-templates-create) — Créer les fichiers d’un projet à partir d’un modèle examiné.
