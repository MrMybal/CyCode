## Utiliser un terminal {#terminal}

Ouvrez Terminal avec Alt+F12. Choisissez un shell, créez ou sélectionnez une session, saisissez les commandes et utilisez les fonctions de copie, de collage et de défilement. Les programmes interactifs s’exécutent dans le terminal sélectionné plutôt que dans la sortie limitée de Compilation.

Les tâches d’exécution du projet peuvent créer un terminal persistant. Arrêtez explicitement le programme ou fermez le terminal qui lui appartient. Restaurer une disposition de travail ne redémarre ni l’ancien shell ni ses processus. La saisie du terminal agit sur un programme ; ce n’est pas une transaction de l’éditeur annulable par Undo.
