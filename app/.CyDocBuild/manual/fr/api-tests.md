Opérations publiques pour Tests du projet.

Ces contrats décrivent le service natif exposé par l’intégration SDK/MCP officielle. La disponibilité dépend du service configuré, du projet et des autorisations. Consultez le [contrat commun](doc:api-links#contract) pour les révisions, les aperçus et les tâches asynchrones.

## Opérations {#operations}

- [`tests_discover`](doc:operation-tests-discover-tests-discover) — Découvrir les tests CTest disponibles dans le projet.
- [`tests_run`](doc:operation-tests-run-tests-run) — Exécuter les tests du projet sélectionnés.
- [`tests_cancel`](doc:operation-tests-cancel-tests-cancel) — Demander l’arrêt de l’exécution des tests du projet.
