# CyCode 0.2.3

Windows x64 · ALPHA · 7 November 2026.

This release adds a per-user Windows installer with EN/FR Setup, Start menu and
optional desktop shortcuts, app-local MSVC runtime and Windows uninstall entry.
Application data and optional toolchains are preserved by uninstall.

Installed copies download and launch the verified Windows installer for updates.
Portable copies use the same ZIP for manual extraction and in-app updates. It uses standard stored ZIP entries accepted by the existing
manifest/SHA-256/rollback engine. No separate public `-update.zip` is produced.
Setup shares the installation ownership file, refuses running copies and pending
recovery, and never kills the application. Native startup checks and explicit
save/close/download/install confirmations are retained.

Versions through 0.2.2 use the old asset name: install this version once with Setup
or extract its portable ZIP in a separate folder. Then use the built-in updater.
Do not overwrite a running copy or copy user data between instances while open.

- [Portable ZIP](https://github.com/MrMybal/CyCode/releases/download/v0.2.3/CyCode-0.2.3-windows-x64.zip).
- [Documentation](https://mrmybal.github.io/CyCode/Documentation.html#/en/updates).

Windows Release compilation, source/data and package authoring checks are performed.
Installer/application/helper execution and a full online update cycle remain
unverified locally. Native test runs remain suspended during the antivirus issue.
Windows 10/11 x64 and OpenGL 3.3 are required. Linux/macOS packages are not supplied.
This packaging release preserves the published editor/services; unrelated local
development is not included. CyCode remains GPL-3.0-only with separate dependency notices.
