# CyCode 0.2.1

The Help menu, contextual buttons and keyboard shortcuts now open an illustrated
English/French CyDoc manual. The complete reader, search, diagrams, images and
API reference are bundled for offline use and published online.

- [Documentation](https://mrmybal.github.io/CyCode-docs/#/en/overview)
- [Documentation française](https://mrmybal.github.io/CyCode-docs/#/fr/overview)
- The README displays the application logo and opens the visual reader.
- GitHub Actions regenerates the same reader on main-branch changes.
- Includes the native development milestones recorded in the changelog.

Windows x64 production binaries were built with native tests disabled. No native
application, MCP runtime or updater was launched for this release. Clean-machine,
native interaction and Linux/macOS acceptance remain pending. This remains a
development IDE with the feature limitations recorded in the manual.

Extract the complete Windows archive to a writable directory. Visual C++ 2022 x64
runtime and OpenGL 3.3 are required. External compilers, language servers, Git and
debuggers must be installed separately. The optional MCP needs CyToolsCore.
The `-update.zip` archive is intended for the application's explicit update flow.
The original application is GPL-3.0-only; bundled dependencies retain their licences.
