# CyCode 0.2.2 — Alpha

[English README](../../../README.md) · [Notes en français](../../../VERSION.fr.md)

Published **6 November 2026**, with a **Windows x64 portable** package.
The product remains **Alpha**: an experimental release for testing and feedback,
with incomplete features and separately installed tools.

## Changes in this release

The local and online manual now uses the current CyDoc reader, with complete
English and French guides, a nested contents tree, global search in the header
(Ctrl+K), six themes, images, galleries and static diagrams.

- 40 practical guides cover editing, projects/Unreal, languages, debugging,
  extensions, revision-control providers and application updates.
- All 227 SDK/MCP operations have translated public references and JSON Schemas.
  Plugin development documents the public C ABI, without publishing implementations.
- Help/context shortcuts open the new local Documentation.html entry point.
- The complete reader is included in both portable and update archives. Existing
  documentation links remain compatible.

Later development-checkout changes, including C++ navigation and snippet
catalogues, are not presented as shipped in the 0.2.2 ZIP. See the
[changelog](../../../CHANGELOG.md) and [developer guide](../../README.md).

## Known limitations

- Only the Windows x64 package is published. Complete Linux/macOS GUI builds and
  runtime behavior remain unvalidated.
- Full Rider feature parity is not reached. Language-server, debugger and VCS
  capabilities depend on installed tools. Highlighting, compilation and semantic
  services are separate capabilities.
- Compilers, SDKs, Unreal Engine, language servers and debugger adapters are
  supplied separately; optional MCP needs the CyToolsCore SDK and its environment.
- Runtime acceptance of the application, MCP and updater for this release remains
  incomplete. Clean-machine installation, real offline-browser, touch and DPI
  acceptance remain separate checks.

These limitations are separate from confirmed bug reports. The release does not
publish a bug-by-bug list; reproducible issues can be reported in the
[issue tracker](https://github.com/MrMybal/CyCode/issues).

## Download and documentation

- [Release 0.2.2 and checksums](https://github.com/MrMybal/CyCode/releases/tag/v0.2.2).

Extract the complete portable archive to a writable directory. Visual C++ 2022 x64
and OpenGL 3.3 are required. Compilers, Git/providers, language servers and debug
adapters are external prerequisites; the optional MCP needs CyToolsCore.
Use the matching `-update.zip` only through the explicit application-update flow.
