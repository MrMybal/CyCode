# CyCode 0.2.2

The local and online manual now uses the current CyDoc reader, with complete
English and French guides, a nested contents tree, global search in the header
(Ctrl+K), six themes, images, galleries and static diagrams.

- 40 practical guides cover editing, projects/Unreal, languages, debugging,
  extensions, revision-control providers and application updates.
- All 227 SDK/MCP operations have translated public references and JSON Schemas.
  Plugin development documents the public C ABI, without publishing implementations.
- Help/context shortcuts open the new local Documentation.html entry point.
- The complete reader is included in both portable and update archives. Existing
  documentation links remain compatible.

[Documentation](https://mrmybal.github.io/CyCodeReader/cycode/Documentation.html#/en/overview)
· [Documentation française](https://mrmybal.github.io/CyCodeReader/cycode/Documentation.html#/fr/overview)

Windows x64 Release binaries and documentation checks were built locally. Native
application, MCP, updater and GUI acceptance were not launched under the existing
antivirus test suspension. Real-browser offline/touch/DPI checks and Linux/macOS
builds remain separate acceptance work. This release does not claim full Rider
feature parity.

Extract the complete portable archive to a writable directory. Visual C++ 2022 x64
and OpenGL 3.3 are required. Compilers, Git/providers, language servers and debug
adapters are external prerequisites; the optional MCP needs CyToolsCore.
Use the matching `-update.zip` only through the explicit application-update flow.
CyCode is GPL-3.0-only; bundled dependencies retain their respective licences.
