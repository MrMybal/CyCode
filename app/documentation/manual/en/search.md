## Find {#find}

| Shortcut | Scope |
|---|---|
| Ctrl+F | Current document |
| Ctrl+Shift+F | Project / workspace |
| Ctrl+Alt+F | File name |
| Double Shift | Rider search everywhere |

## Review results {#results}

Check scope, filters and document revision. Stale results may require refresh. In filterable panels Ctrl+F can focus the filter; inside the editor it keeps document find. Escape clears an active filter field.
