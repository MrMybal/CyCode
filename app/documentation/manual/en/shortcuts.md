## Shortcuts {#shortcuts}

| Shortcut | Action |
|---|---|
| Ctrl+S | Save |
| Ctrl+Shift+F | Project search |
| Ctrl+Alt+F | File-name search |
| Double Shift | Search everywhere |
| Ctrl+F1 | Documentation |
| Shift+F1 | Context help |

Rider, Visual Studio and VS Code profiles retain their differences and overrides. F1 opens help outside VS Code; VS Code keeps F1 for the action palette. Indexed commands/source retain the complete tables.
