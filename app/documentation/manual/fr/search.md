## Chercher {#find}

| Raccourci | Portée |
|---|---|
| Ctrl+F | Document courant |
| Ctrl+Shift+F | Projet / espace de travail |
| Ctrl+Alt+F | Nom de fichier |
| Double Shift | Recherche globale Rider |

## Parcourir les résultats {#results}

Contrôlez le périmètre, les filtres et la révision du document. Un résultat devenu périmé peut nécessiter une nouvelle recherche. Dans les panneaux filtrables, Ctrl+F peut cibler le champ de filtre ; dans l’éditeur il conserve la recherche du document. Escape efface le filtre lorsque son champ est actif.
