## Contrôle de versions {#providers}

Git est le fournisseur par défaut de CyCode. Les fournisseurs externes et associations de racine sont décrits dans VersionControl et les guides Perforce, Subversion, Mercurial et Diversion. Chaque action a son périmètre, ses confirmations et ses limites ; la présence du plugin ne remplace pas le client ou le serveur du fournisseur.
