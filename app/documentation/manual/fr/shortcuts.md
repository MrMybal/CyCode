## Raccourcis {#shortcuts}

| Shortcut | Action |
|---|---|
| Ctrl+S | Save |
| Ctrl+Shift+F | Project search |
| Ctrl+Alt+F | File-name search |
| Double Shift | Search everywhere |
| Ctrl+F1 | Documentation |
| Shift+F1 | Context help |

Les profils Rider, Visual Studio et VS Code gardent leurs différences et réglages personnalisés. F1 ouvre l’aide hors du profil VS Code ; dans VS Code, F1 conserve la palette d’actions. Consultez les commandes et le code indexés pour les tables complètes.
